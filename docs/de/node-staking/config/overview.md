# Übersicht

In diesem Abschnitt erfahren Sie, wie Sie den Smart Node-Stack konfigurieren und alle Einstellungen nach Ihren Wünschen anpassen können.
Sie müssen ihn vor dem ersten Betrieb des Stacks konfigurieren, können aber jederzeit zurückkehren und ihn neu konfigurieren, sobald er läuft.

## Voraussetzungen

Bevor Sie Ihren Smart Node konfigurieren, stellen Sie bitte sicher, dass Sie:

- Eine Node-Maschine (oder virtuelle Maschine) mit installiertem und konfiguriertem Betriebssystem haben
- Die Maschine gesichert haben (über die Anleitung [Sichern Ihrer Node](../securing-your-node))
- Den Smart Node darauf installiert haben

## Anleitungen

[Konfiguration des Smart Node-Stacks (Docker / Hybrid-Modus)](../config-docker) ist die Anleitung, die Sie verwenden sollten, wenn Sie den Docker-Modus oder Hybrid-Modus nutzen möchten.

[Konfiguration des Smart Node-Stacks (Native-Modus)](../config-native) ist die Anleitung, die Sie verwenden sollten, wenn Sie den Native-Modus nutzen möchten.

[Erweiterte Smart Node-Konfiguration für Docker-Modus](../advanced-config) ist eine Ergänzung zur Docker-Anleitung, die einige zusätzliche Funktionen und Features zeigt, die Sie interessieren könnten (wie z.B. den "Reverse Hybrid"-Modus oder das Anpassen der Docker-Container-Flags).
